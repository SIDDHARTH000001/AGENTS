# 🎬 YouTube Shorts Generator Agent

Turn **long videos into viral YouTube Shorts** in minutes.
Powered by **Gemini + LangGraph** for smart clip selection and **Faster-Whisper** for perfectly synced subtitles (no awkward audio lag).

---

## ✨ What it does

* Finds the best moments in long-form videos
* Cuts them into Shorts-ready clips (under 60s, vertical format)
* Auto-generates subtitles with accurate timing
* Exports directly for YouTube, Reels, or TikTok

---

## 🚀 How it works

1. Drop your video into the input folder
2. Run the agent
3. Get Shorts with synced subtitles in the output folder

That’s it. No manual editing, no subtitle syncing, just ready-to-upload Shorts.
